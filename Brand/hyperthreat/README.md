# Hyperthreat Brand Assets

Drop the silver-gradient logo PNG in this folder:

- `hyperthreat-logo.png` — source (silver gradient, transparent background preferred)
- `hyperthreat-logo-print.png` — generated by `tools/gen_print_logo.py` (inverted, white-flattened, for B&W laser print)

To regenerate the print variant after updating the source:

```powershell
C:\G\python.exe tools\gen_print_logo.py
```
